# Lite TV Launcher + tvtool.py
Needs: Python 3, ADB, and Android Studio or Gradle (to build).
  python3 tvtool.py all <TV_IP>      # connect > analyze > bloat review > build > install > test > set home
Individual: connect | analyze | bloat | build | install | test | sethome | rollback
Hold OK on an app = toggle favorite (favorites sort first).
Backups + rollback state: ./backups/
